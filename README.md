# 1llum1Hearts
 A cozy focus timer with a filling heart animation.

**1llum1Hearts** is a lightweight web application designed to create a warm and focused working environment. Inspired by [LifeAt](https://lifeat.io), this project was born from my desire to have a quiet digital corner where it’s easier to concentrate on tasks. I built this primarily for myself, but I hope it helps others who struggle with focus as well.

> **Note:** This project is developed with the help of AI. It is my first experience in development, so the code might not be perfect, but it is made with love ✨

## 🌟 Features

- **Heart Timer:** The central element is a heart that gradually fills up during focus sessions and empties during breaks.
- **Simple Controls:** Play/Pause button located directly on the heart.
- **Flexible Timing:**
  - Presets: **1 hour / 30 minutes / 15 minutes**.
  - Custom adjustment: Use ▲▼ arrows next to the timer to change time by ±1 minute.
- **Automatic Breaks:** Breaks start automatically after a session; duration is customizable.
- **Session Tracking:** Circles below the panel track completed focus sessions.
- **To-Do List:** Add tasks, check them off, and watch the progress bar at the bottom update with completion percentage.
- **Customizable Backgrounds:**
  - 8 built-in backgrounds.
  - Upload your own image via file upload, gallery, URL, or drag-and-drop.
- **Draggable Interface:** Panels can be moved anywhere on the screen.
- **Privacy First:** All data (tasks, background settings, timer preferences) is saved locally in your browser. Nothing is sent to any server.

## 🚀 How to Run

No installation, build tools, or servers required.

1. Download the `index.html` file.
2. Open it in any modern web browser.

*Internet connection is only required to load fonts. The app works offline without them.*

## 🛠️ Technologies

- Pure **HTML + CSS + JavaScript**.
- Single-file architecture (everything is contained within `index.html`).

# 1llum1Hearts (Русская версия)

🤎 Уютный таймер фокусировки с наполняющимся сердцем.

**1llum1Hearts** — небольшое веб-приложение, которое создаёт тёплую рабочую среду. Идея вдохновлена сайтом [LifeAt](https://lifeat.io): мне хотелось иметь свой тихий уголок, где проще сосредоточиться на делах. Я делаю его в первую очередь для себя — и буду рада, если он поможет и другим людям, у которых есть проблемы с концентрацией.

## Как это работает

- В центре — сердце-таймер: во время фокуса оно постепенно наполняется, во время отдыха — опустошается.
- Кнопка ▶ / ⏸ находится прямо на сердце.
- Пресеты времени: **1 час / 30 минут / 15 минут**, а стрелки ▲▼ рядом с часами позволяют поставить своё время (±1 минута).
- Перерыв запускается автоматически, его длину можно настроить.
- Кружки под панелью считают выполненные сессии.
- Панель **заметок** (to-do): добавляйте задачи, отмечайте их галочкой — внизу шкала с процентами выполнения.
- **Фоны**: 8 встроенных + можно поставить свою картинку — из файла, из галереи, по ссылке или просто перетащив её мышкой.
- Панели можно перетаскивать в любое место экрана.
- Всё (задачи, фон, время) сохраняется в браузере — ничего никуда не отправляется.

## Как запустить

Никаких установок, сборок и серверов не нужно:

1. Скачайте файл `index.html`.
2. Откройте его в любом браузере.

Интернет нужен только для загрузки шрифтов; без них приложение тоже работает.
